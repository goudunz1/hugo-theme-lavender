## Basic Emphasis

This is *italic text* and this is **bold text** and this is ***bold italic***.
This is _underscore italic_ and this is __underscore bold__.

## Strikethrough and Combined

~~This text is struck through.~~

This is ***~~bold italic struck through~~*** and this is **~~bold struck through**~~.

## Edge Cases

Emphasis *inside a **word** like this* and **bold with *nested italic*** inside.

Mid-word em*pha*sis test.

Trailing and leading: * this has space after asterisk *, ** this with double **.
